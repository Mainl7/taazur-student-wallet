# Database notes

العلاقات الأساسية: `School → Student → Wallet → WalletTransaction`، و`Student → Card`. يمكن أن يمتلك الطالب بطاقات تاريخية متعددة؛ يضمن `publicToken` الفريد أن رمز QR/Barcode لا يكشف هوية الطالب.

الحدود والمبالغ تستخدم `DECIMAL(12,2)`، وليس float. يوجد فهرس زمني لعمليات الطالب والمدرسة، وقيد فريد على مرجع المعاملة ومفتاح idempotency. يجب احتساب حد اليوم والأسبوع داخل نفس المعاملة قبل اعتماد الخصم في المرحلة التالية.
